SHIFTLY — BETA 1.0
===================

محتويات الحزمة
- Index.html: واجهة التطبيق الرئيسية.
- css/: ملفات التصميم.
- js/: وظائف التطبيق وإدارة الموظفين والجدول والتخزين.
- manifest.webmanifest و sw.js: دعم التثبيت والعمل دون اتصال بعد أول زيارة ناجحة.
- icons/: أيقونات التطبيق.

طريقة التجربة محلياً
1) فك ضغط المجلد كاملاً دون تغيير أسماء الملفات.
2) افتح Index.html في Acode للمعاينة.
3) اختبر إضافة الموظفين وإنشاء الجدول والنسخ الاحتياطي والاسترجاع.

طريقة النشر كتطبيق ويب قابل للتثبيت (PWA)
1) أنشئ مستودع GitHub جديداً.
2) ارفع جميع محتويات مجلد Shiftly إلى جذر المستودع، وليس ملف ZIP نفسه.
3) من Settings ثم Pages اختر Deploy from a branch.
4) اختر الفرع main والمجلد /(root)، ثم Save.
5) انتظر رابط GitHub Pages وافتحه عبر HTTPS على الهاتف.
6) من قائمة Chrome اختر Add to Home screen أو Install app إذا ظهر الخيار.

ملاحظات مهمة
- يجب رفع الملفات مع الحفاظ على أسماء المجلدات وحالة الأحرف.
- لا ترفع مجلد Shiftly داخل مجلد آخر داخل المستودع؛ يجب أن يكون Index.html في الجذر.
- البيانات محفوظة محلياً على الجهاز والمتصفح، وليست متزامنة تلقائياً بين الأجهزة.
- النسخ الاحتياطي JSON ضروري قبل مسح بيانات المتصفح أو تغيير الجهاز.
- PWA تحتاج أول زيارة ناجحة عبر HTTPS حتى يتم تخزين ملفات العمل دون اتصال.
- لم تُنتج هذه الحزمة APK؛ إنها نسخة ويب قابلة للتثبيت من المتصفح.

نظام المناوبات
- الأحد إلى الخميس: 24 ساعة.
- الجمعة والسبت: 12 ساعة لكل يوم، مع تحديد وقت البداية من الإعدادات.
